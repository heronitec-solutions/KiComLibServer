A backup is an encrypted archive of the database and the Data Protection key ring. It includes the library, users, groups, sessions, settings, and stored secrets for Git, distributors and directory login. Git mirrors and rendered pages are left out and are built again after a restore.

The passphrase is not stored. You need it to restore the backup, including on another machine. The server restarts after a restore so the restored key ring is loaded. Older PostgreSQL dumps can still be uploaded; those restore the database only.

At least 12 characters. Surrounding spaces are ignored.
